
# 🎮 Dededen-KAÇ-3

**Dededen-KAÇ-3**, Minecraft temalı, düşmanlarla mücadele ettiğin ve hayatta kalmaya çalıştığın bir aksiyon oyunudur. Python ve Pygame kullanılarak geliştirilmektedir.

Oyun sürekli güncelleniyor ve yeni özellikler eklenmeye devam ediyor!

## ✨ Oyuna Eklenen Özellikler

- 🛡️ **Anti-Cheat Sistemi:** Oyunda hileleri ve beklenmeyen oyun verilerini kontrol etmeye yönelik güvenlik mekanizmaları bulunur.
- 🔐 **Kod Bütünlüğü Kontrolü:** SHA-256 tabanlı bütünlük kontrolü eklendi.
- 🌐 **Multiplayer:** Çok oyunculu oyun sistemi eklendi.
- 🔫 **Silah Sistemi:** Farklı silahlar ve saldırı mekanikleri.
- 🛒 **Market Sistemi:** Oyun içi para ile alışveriş yapabilme.
- ❤️ **Can Sistemi:** Oyuncu sağlık ve hasar mekanikleri.
- 👾 **Düşmanlar:** Minecraft temalı farklı düşmanlar.
- ⚙️ **Admin Sistemi:** Oyun içerisinde özel admin özellikleri.

## 📱 Nasıl Çalıştırılır?

Oyun Android cihazlarda **Pydroid 3** üzerinden çalıştırılabilir.

1. Pydroid 3 uygulamasını yükleyin.
2. Gerekli Pygame bağımlılığını kurun.
3. Proje dosyasını indirin.
4. `dededenkaç3MultiPlayer.py` dosyasını çalıştırın.
